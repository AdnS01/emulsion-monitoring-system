# Web Application – Emulsion Monitoring System

## Overview

This web application provides **visualization and traceability** for an industrial emulsion monitoring system.

It is used to display and archive data generated by an Arduino-based controller, and transmitted via an ESP8266 serial-to-HTTP gateway.

All data is stored in a **MySQL database** and accessed through a **PHP backend**.

## Functional Scope

### Authentication
- Session-based user authentication
- Restricted access to production data

![Authentication](./docs/Authentication.png)

### Dashboard (Home)
- Weekly trend of **average emulsion concentration**
- Line chart generated using **Chart.js**
- Selection of production line (TF – tréfileuse)

![Home](./docs/Home.png)

### Concentration History
- Tabular view of concentration measurements
- Filters:
  - Production line (TF)
  - Date range
- Export of filtered data to **Excel-compatible format**

![Concentration History](./docs/Concentration_History.png)

### Operation History
- Log of automatic corrective actions:
  - Water addition
  - Oil addition
- Filters by production line and date range
- Data export for reporting

![Operation History](./docs/Operation_History.png)

## Backend and Data Flow

- Backend implemented in **PHP**
- Data stored in **MySQL**
- Communication with the embedded system via an ESP8266 **HTTP POST** gateway
- Each record contains:
  - Date
  - Time
  - Measurement value or operation type
